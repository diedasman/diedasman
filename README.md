### protoMIDI

[View protoMIDI](https://github.com/diedasman/protoMIDI)

nRF52840-based HID macropad with the control architecture of a small MIDI controller, developed as a v1.0 custom PCB and enclosure.

* Custom PCB with eight illuminated buttons, two rotary encoders and toggle switch
* Two-piece CAD-designed enclosure with STEP and STL exports
* Public DFM pack with Gerbers, drill files, enclosure exports and BOM notes
* ZMK-based HID firmware, with the Rev A prototype preserved as historical reference

### Slim485

[View Slim485](https://github.com/diedasman/Slim485)

USB-C to RS485 adapter for embedded projects, field wiring and bench work where a small directly pluggable serial interface is useful.

* USB-C to half-duplex RS485 interface built around a CP2102N USB-to-UART bridge and SP3485 transceiver
* Castellated edge pads for `5V`, `A`, `B` and `GND`
* USB input protection, data-line ESD protection, bus termination and biasing
* Public hardware package with Gerbers, JLCPCB BOM, placement data and STEP export
